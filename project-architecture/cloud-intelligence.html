🧠 Intelligence Models

Algorithms & Predictive Models

Three distinct models run continuously in the cloud to compute irrigation targets, fertilization doses, and pest forecasts.

💧
FAO-56 Evapotranspiration Model
Penman–Monteith Reference ET
Calculates reference evapotranspiration (ETo) from weather data, then multiplies by the crop coefficient (Kc) for the current growth stage to derive the daily irrigation target.
ETo = [0.408Δ(Rn−G) + γ(900/(T+273))u₂(es−ea)] / [Δ + γ(1+0.34u₂)]
Irrigation Target = ETo × Kc(crop stage)
🧪
Dynamic Fertigation Model
EC Feedback Control Loop
Continuously monitors soil EC and moisture tension. Computes the nutrient dose required to reach the EC target without leaching, and only dispenses when moisture tension is in the optimal absorption window.
Dose = (EC_target − EC_current) × soil_volume × calibration_factor
Constraint: θ (moisture tension) must be in optimal range
🐛
GDD Pest Forecasting Model
Growing Degree Day Accumulation
Accumulates daily heat units from DHT22 microclimate data. When the cumulative GDD crosses a species-specific threshold, a pest emergence alert is issued 7 days in advance via push notification.
GDD_daily = (T_max + T_min) / 2 − T_base
Alert when: ∑GDD ≥ Threshold_pest_species
🔄 State Machine

Central Coordination Engine States

The engine cycles through these states continuously, evaluating all sensor data and model outputs every minute.

🟢

MONITORING

All systems nominal. Sensors polled every 60s. No action required.

💧

IRRIGATING

Irrigation valve opened. Flow meter confirms delivery. Timer tracks volume.

🧪

FERTIGATING

Nutrient pump active. EC monitored in real-time. Stops at EC target.

🐛

PEST_ALERT

GDD threshold crossed. Push alert sent. Spray schedule queued.

🚫

INTERLOCK

One or more interlocks active. Conflicting actions blocked automatically.

🌧️

RAIN_SKIP

Weather API forecast triggered. Irrigation paused until forecast clears.
